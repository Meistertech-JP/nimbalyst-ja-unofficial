# Nimbalystへようこそ

このプロジェクトは、設定なしで探索できる小さなワークスペースです。ファイルを開いて文章を編集し、エージェントに依頼し、トラッカーの参照をたどってみてください。文書、データ、計画、ビジュアルエディターがどのようにつながるかを確認できます。

## 試してみること

- この文書に入力してみましょう。`/`、`#`、`@`も試せます。
- エージェントに、このファイルの先頭へ要約を追加するよう依頼し、変更を確認します。
- [ダッシュボードのモックアップ](dashboard.mockup.html)で画面をデザインします。
- エージェントにモックアップの変更を依頼します。
- 左ナビゲーションの`< >`アイコンからエージェントモードを開き、過去のセッションと、そのセッションが変更したファイルを右側のナビゲーションで確認します。
- [売上スプレッドシート](revenue.csv)で月別の実績を確認します。
- [指標モデル](metrics.calc.md)の前提を変更して、計算結果の変化を確認します。
- [構成図](architecture.excalidraw)で、元データからリリースまでの流れをたどります。
- [製品概要](product-brief.md)で、プロジェクトの成果物を埋め込んだ文書を読みます。
- [リリースチェックリスト](launch-checklist.md)で、目標を具体的な作業へ分解します。
- [チュートリアルの実施計画](planning/plan-tutorial-walkthrough.md)で、Markdown文書がトラッカー項目にもなることを確認します。
- [不具合のサンプル](nimbalyst://{{TRACKER_ISSUE_KEY:EXAMPLE_BUG}})で、実際の課題に近い例を確認します。
- 左ナビゲーションの上から3番目のアイコンでトラッカーモードを開き、統合された作業管理を試します。
- エージェントに、このプロジェクトのファイルからWikiを作成するよう依頼します。Wikiモードで作成されたページを読み、編集してみてください。

## プロジェクトのWiki

エージェントとの作業では、多くの資料が生まれます。Wikiは、その内容をページに整理する場所です。決定事項、未解決の課題、各要素のつながりを読み、編集し、次の方針を示せます。

Wikiモードのローカル領域はアカウントなしで使用できます。ページはプロジェクト内の通常のファイル（既定では`nimbalyst-local/wiki`）として保存され、履歴を比較・復元できます。ページ同士をリンクでき、文書のほかにモックアップ、図、スプレッドシートもページにできます。ファイルの「Wikiにコピー...」で取り込めます。チームページはNimbalyst Teamsの機能です。

## 作業の追跡

[実施計画](planning/plan-tutorial-walkthrough.md)は、読みやすいMarkdownファイルであり、トラッカー項目としても表示されます。[不具合のサンプル](nimbalyst://{{TRACKER_ISSUE_KEY:EXAMPLE_BUG}})は、ステータス、優先度、履歴、詳細な本文を持つネイティブのトラッカー項目です。トラッカーモードで両方の作業管理方法を比較できます。

## キーボードショートカット

WindowsとLinuxでは、表のCmdをCtrlに読み替えてください。

| 操作 | ショートカット |
| --- | --- |
| プロジェクトマネージャーを開く | `Cmd+P` |
| ファイルモードに切り替える | `Cmd+E` |
| エージェントモードに切り替える | `Cmd+K` |
| トラッカーモードに切り替える | `Cmd+T` |
| Wikiモードに切り替える | `Cmd+D` |
| AIチャットの表示を切り替える | `Cmd+Shift+A` |
| プロジェクト内を検索する | `Cmd+Shift+F` |
| 現在のファイルを保存する | `Cmd+S` |

## 自分のプロジェクトを始める
