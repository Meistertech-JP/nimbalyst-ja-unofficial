# リリースチェックリスト

文書、データ、デザインにまたがる作業を、このチェックリストで整理します。

## 伝える内容

- [ ] 製品概要の対象者が明確になっているか確認する。
- [ ] すべての主要指標に参照元があるか確認する。
- [ ] プロジェクト責任者とリリース準備状況のメモを確認する。

## データ

- [ ] 売上スプレッドシートに最新月を追加する。
- [ ] リリース目標までの差額を再計算する。
- [ ] 解約による予想外の変化を調べる。

## デザイン

- [ ] ダッシュボードを狭い幅で確認する。
- [ ] 埋め込み表示でもラベルが読めるか確認する。
- [ ] 対象範囲に影響する決定事項を記録する。

## リリース

- [ ] 未解決のトラッカー項目を整理する。
- [ ] リリースを妨げるすべての課題に担当者を割り当てる。
- [ ] チーム向けの短い進捗報告を書く。
