# チュートリアルの実施計画

## 目標

Nimbalystプロジェクトでは、複雑な初期設定をしなくても、文書、データ、ビジュアルなデザイン、作業管理をまとめて扱えることを、新しい利用者に知ってもらいます。

## 進め方

- [x] 分かりやすいプロジェクトの入口を用意する。
- [x] スプレッドシートを開いて元データを確認する。
- [x] 指標モデルの前提値を変更する。
- [ ] 埋め込みのダッシュボードと専用エディターを比較する。
- [ ] トラッカーの参照からこの計画へ戻る。
- [ ] エージェントセッションで成果物を1つ改善する。
- [ ] エージェントにプロジェクトのファイルからWikiを作成してもらい、Wikiモードでページを編集する。

## 成功の基準

利用者が各ファイル形式を行き来し、フォルダー構成の意図を理解し、計画書を文章としてもトラッカー項目としても活用できれば、このチュートリアルの目標達成です。
