# Wiki sources

`docs/wiki/` contains the maintained sources for the public Japanese and English Wiki: 29 articles, `_Sidebar.md`, and `_Footer.md`. Article links use GitHub Wiki page names, rather than repository-relative Markdown paths.

Update both languages when technical information changes and preserve version-specific verification limits. Publish reviewed changes to the separate Wiki repository, then compare all source files and rendered articles. Changes here do not automatically update the public Wiki.

Release preparation notes, review receipts and intermediate drafts belong outside the tracked source tree. Current README and Release Notes are maintained at the repository root.
