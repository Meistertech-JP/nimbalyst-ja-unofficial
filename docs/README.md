## Upstream technical documentation

Other architecture, design, development, platform and historical release documents are retained from upstream Nimbalyst. They describe upstream components and may include historical APIs, planned work, examples or links to resources maintained outside this repository. They are not evidence that this fork supplies every upstream platform package, operates the upstream service, or repeats all upstream runtime checks.

For a code change, compare the referenced symbols, scripts and configuration with the checked-out source. For installation and update instructions for this edition, use the Windows and Wiki guides above. Official signing, release-channel promotion and automatic updates described in inherited guides do not apply to the unofficial edition.

Agent instruction files describe development tools and product integrations. They are not records of individual development conversations. Internal reports, approval histories, raw audit output and intermediate release drafts are excluded from the public source tree.
