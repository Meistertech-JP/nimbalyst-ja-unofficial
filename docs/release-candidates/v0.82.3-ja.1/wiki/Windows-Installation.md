# Windows導入・更新

[English](Windows-Installation-English.md) · [ホーム](Home.md)

対象はWindows x64の未署名NSISとポータブルZIPです。v0.82.3-ja.1は未公開の候補です。公開済みファイルは[本リポジトリのReleases](https://github.com/Meistertech-JP/nimbalyst-ja-unofficial/releases)で確認してください。

## 取得と確認

対象バージョンのファイルとSHA256SUMS.txtを取得し、PowerShellの `Get-FileHash -LiteralPath <ファイル> -Algorithm SHA256` で同じファイル名の値と照合します。不一致なら実行しません。アプリとインストーラーは未署名です。Windowsやセキュリティソフトの保護を無効にする手順は提供しません。

## インストール

編集中の文書を保存し、既存の本版を終了します。製品名が「Nimbalyst 日本語版（非公式）」であることを確認し、公式版とは別の場所へ現在のユーザー用にインストールします。管理者への昇格を提供しない構成です。完了後に本版のショートカットから起動します。完了時の自動起動は無効です。

アプリIDは `jp.meistertech.nimbalyst.ja.unofficial` です。Markdownの「プログラムから開く」には本版固有の登録を追加しますが、既定アプリ、Explorer UserChoice、`nimbalyst://` の既定ハンドラーは変更しない構成です。公式版との同時利用はサポートしません。

## ZIP

新しい書込み可能なディレクトリへ全内容を展開し、`Nimbalyst 日本語版（非公式）.exe` を起動します。EXEだけを取り出したり、ZIP内から直接起動したりしないでください。DLLとresourcesを含む全ファイルを保持してください。

ポータブルとはインストーラーなしで配置できる意味です。ユーザーデータをEXEの隣へ保存する意味ではありません。既定プロファイルはインストーラー版と同じ `%APPDATA%\Nimbalyst 日本語版（非公式）` です。異なる版を同じプロファイルで同時に起動しないでください。

## 更新とデータ

公式の自動更新と手動更新確認は無効です。本リポジトリのReleaseから手動更新します。作業を保存して終了し、プロジェクト文書をバックアップしたうえで対象版の変更と制限を確認します。ZIP更新は旧ディレクトリへの上書きではなく新しい場所へ展開します。ダウングレード後のプロファイル互換性は保証しません。

v0.82.3ではSQLiteスキーマ0055が、待機中Tracker編集に同期基準リビジョンを保存する列を追加します。合成データの移行・保持・ロールバック試験が成功しています。通常インストーラーによるv0.82.1-ja.1からの更新でも55の適用、英語設定と全10テスト文書のハッシュ保持、既存Tracker表示を確認しました。すべての既存プロファイルやダウングレードの互換性を保証するものではありません。

## 認証と言語

表示言語は設定でSystem、English、日本語を選択します。認証メールはアプリを起動している同じPCで開きます。localhostの `127.0.0.1` は操作端末自身を指すため、スマートフォンで開いてもPCのアプリへ戻れません。URLの書換えや外部へのポート開放は不要です。認証URLやトークンは共有しないでください。

## アンインストール

Windowsのアプリ一覧で本版を選択します。本版がまだ所有する登録・ショートカットを削除し、ユーザーデータは保持する構成です。ZIP版は終了後に展開先のみを削除できます。文書やプロファイルの削除とは別の操作です。
