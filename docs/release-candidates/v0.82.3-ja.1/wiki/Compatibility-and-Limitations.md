# 互換性と制限

[English](Compatibility-and-Limitations-English.md) · [ホーム](Home.md)

- v0.82.3-ja.1は未公開候補で、現在の正式版はv0.82.1-ja.1です。候補の最終品質判定はまだ確定していません。
- 未署名Windows x64向けです。他OSのバイナリは提供しません。iOSシミュレーター試験はWindowsやiOS実機の全面保証ではありません。
- 公式版との同時利用はサポートしません。既定プロファイルを共有する本版の複数配置も同時使用しないでください。
- 旧暗号化方式のチーム復旧には更新された同期サーバーと対応クライアントが必要です。本番組織・独立クライアントでの完全な復旧手順は未検証です。
- 合成DBの移行試験は既存の全ユーザーデータの互換性を証明しません。更新前に文書をバックアップしてください。ダウングレード互換性は保証しません。
- Google認証、特殊な認証復旧、サービス側セッション失効、別ユーザーを含むNTFS実効アクセスは未検証です。ログアウトによるローカル状態削除とサーバー側失効は別です。
- Windowsのsymlink fixture EPERMを保持しています。fixture作成で停止したsandbox拒否動作は未確認です。未確認を既知の脆弱性と断定しません。
- 先行iOS性能試験の失敗原因を修正し、最新シミュレーター試験は528実行（6 SKIPを含む）・0 FAILでした。物理端末やすべての履歴構成での性能を保証するものではありません。
- 動的翻訳の全経路、全画面・DPI、外部スクリーンリーダー、WSL実環境の全経路は未検証です。キー数一致を全画面翻訳済みとは扱いません。
- 上流v0.82.3はPrereleaseです。本版は固定コミットを基準とし、その後の上流修正を自動的に含みません。

自動更新はありません。未署名の警告や組織のセキュリティ制限を回避せず、ファイルの取得元・版番号・チェックサムを確認してください。
