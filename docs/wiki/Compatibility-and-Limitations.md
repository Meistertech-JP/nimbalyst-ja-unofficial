# 対応環境と制限事項

v0.84.0-ja.1はWindows x64向けの非公式日本語版です。本家v0.84.0はPrerelease。日本語版を通常Release・Latestとして公開していますが、公式認定・安定性保証ではありません。

## 特に重要な制限

- **Windows全テストの108 FAILは未解決です。** 全テスト合格版ではありません。件数だけで全件を新規重大回帰とも、全件を無害な環境差とも判断していません。
- **長文MarkdownでCPU使用率が高くなる問題が残っています。**
- **未署名・手動更新です。** 公式版の自動更新・更新確認は無効です。取得元とチェックサムを確認し、保護機能を無効にしないでください。
- **Wiki公開・チーム機能には対応サーバーと権限が必要です。** 実同期・共同編集サーバー、実組織、旧新サーバー間の相互運用は未検証です。
- 公式版との同時利用、異なる版で同じプロファイルを同時使用する運用はサポートしません。旧版へのダウングレードも未検証です。

## 確認した範囲と、確認していない範囲

専用環境で通常Windows製品の起動・言語切替・再起動保持、新規導入、前版からの更新時の設定・文書・Tracker表示を確認しています。本番メール認証も確認しましたが、全配布形態の新規認証やGoogle認証、サーバー側のセッション失効までは網羅していません。

一部の音声ボタンには英語表示が残ります。翻訳キーの一致は全画面・全動的表示・読み上げの保証ではありません。実マイク・実音声認識API、全DPI、外部スクリーンリーダー、負荷時Wiki文脈処理、端末資源残留の一般的な解消も未確認または未解決です。未検証を確認済みの不具合や脆弱性と同一視しないでください。

正確な母集団・環境・PASS/FAIL/SKIP/NOT RUNと過去版の記録は[テストと品質検証](Testing-and-Verification)、保存先の境界・認証等の細部は[詳細な既知制限](https://github.com/Meistertech-JP/nimbalyst-ja-unofficial/blob/main/docs/KNOWN_LIMITATIONS_v0.84.0-ja.1.md)へまとめています。
