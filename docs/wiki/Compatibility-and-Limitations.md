## 公式版から分離するもの

| 項目 | 本版の方針 |
| --- | --- |
| アプリ識別子 | `jp.meistertech.nimbalyst.ja.unofficial` |
| 製品名 | Nimbalyst 日本語版（非公式） |
| 既定インストール先 | `%LOCALAPPDATA%\Programs\nimbalyst-ja-unofficial` |
| 既定ユーザーデータ | `%APPDATA%\Nimbalyst 日本語版（非公式）` |
| 公式更新 | 自動取得・適用・手動確認を無効化 |
| Windows URL登録 | `nimbalyst://`の既定ハンドラーを取得しない |
| 認証 | インスタンスごとのnonceを使うlocalhost callback |

分離は公式版との同時利用の保証ではありません。同時利用はサポートしません。既存の公式版データを移動・削除しない構成です。認証以外のnimbalyst://リンクは既存の登録先で開く場合があります。
