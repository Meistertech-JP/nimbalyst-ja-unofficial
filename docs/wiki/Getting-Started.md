# はじめに

Nimbalystは、ファイルの編集、AIエージェントとの作業、セッション管理、トラッカーを一つのワークスペースで扱うデスクトップアプリケーションです。Markdownだけでなく、コード、図、表などを扱う編集機能があります。これらは本家Nimbalystの機能です。

日本語版（非公式）は、デスクトップUIの日本語表示と表示言語の設定を追加したフォークです。日本語化に加え、公式版とは別のWindowsアプリ識別子・保存先、公式更新の無効化、localhost認証などの配布上の変更があります。Nimbalyst, Inc.の承認・サポートは受けていません。

## 入手する版

[v0.82.4-ja.1のRelease](https://github.com/Meistertech-JP/nimbalyst-ja-unofficial/releases/tag/v0.82.4-ja.1)から取得します。本家v0.82.4を基準とするWindows x64向けの未署名版です。NSIS、ポータブルZIP、対応ソースZIPとSHA256SUMS.txtを提供します。インストーラーはWindowsのアプリ一覧とショートカットを使う配置、ポータブルZIPは展開したディレクトリから実行する配置です。ZIP版も設定をEXEの横に保存するわけではありません。提供ファイルと検証範囲はReleaseノートを参照してください。

[Windowsへの導入と更新](Windows-Installation)で、取得するファイル名、チェックサム照合、配置方法を確認してください。旧v0.81.7-ja.2はソース限定Prereleaseで、現在のWindows配布物とは異なります。

## 初回起動

初回案内では動作モードやチュートリアルへの導線が表示されます。規約やプライバシーポリシーは内容を確認して判断してください。エージェントの設定画面が表示されても、後から設定する選択肢があります。実際にエージェントを使用するには、そのプロバイダーの認証・利用条件を満たす必要があります。

表示言語はアプリ設定の「詳細設定」で選択します。日本語・英語・システム設定に対応します。[表示言語の設定](Display-Language)を参照してください。新しいチュートリアルは作成時の表示言語に応じた内容になりますが、言語を変更しても既存の文書や会話は書き換えません。

Nimbalystアカウントのログインと、ClaudeやCodexなどのエージェント認証は別です。Nimbalystのメール認証は[アカウント認証](Account-and-Authentication)で説明します。

## ファイルとプロジェクト

作業するフォルダーをプロジェクトとして開き、ファイル一覧から文書を選択します。AIへ変更を依頼する場合も、作業対象のプロジェクトとファイルを確認してください。初めて試す場合は、元の文書を変更しない専用フォルダーやチュートリアルを使用できます。

Local WikiやTeam Wikiはアプリ内の機能です。このGitHub Wikiは配布版の利用・開発資料であり、アプリ内のWikiとは保存場所も用途も異なります。

起動・表示・ログインに問題がある場合は[トラブルシューティング](Troubleshooting)、検証範囲は[対応環境と制限事項](Compatibility-and-Limitations)を参照してください。
