# はじめに

Nimbalystは、ファイル編集・AIとの会話・タスク管理を一つの作業画面にまとめたアプリです。ここでは非公式日本語版v0.84.0-ja.1の使い始め方と、新しい操作を紹介します。

## 最初の3ステップ

1. [Release](https://github.com/Meistertech-JP/nimbalyst-ja-unofficial/releases/tag/v0.84.0-ja.1)からWindows x64用のインストーラーかPortable ZIPを取得し、[導入ガイド](Windows-Installation)に沿って照合・導入します。
2. 初回案内でモードを選び、利用規約・プライバシーポリシーを確認して進みます。チュートリアルから試すことも、作業用フォルダーをプロジェクトとして開くこともできます。
3. エージェントを使うときに、利用するサービスの設定・認証を行います。後で設定する選択肢もあります。実際の利用条件・料金はサービス側で確認してください。

ファイル一覧から文書を選んで編集できます。AIに変更を頼む前には、開いているプロジェクトと対象ファイルを確認しましょう。初めて試す場合は、元の文書を変更しない専用フォルダーやチュートリアルを使えます。

日本語・英語の切替は[表示言語の設定](Display-Language)へ。NimbalystのログインとClaude・Codex等の認証は別です。[アカウント認証](Account-and-Authentication)で説明します。

## 新版の機能を使う

### 関連する会話をまとめる

左側でエージェント表示に切り替え、セッション一覧の作成メニューから「新しいワークストリーム…」を選びます。既存のセッションはメニューの「ワークストリームへ移動…」からまとめられます。

Workstreamは会話を整理する名前付きのフォルダーです。その配下の会話を切り替えながら、関連ファイルを共通のエディタータブで扱えます。Gitのworktreeを作ったり、エージェントの指揮関係を設定したりする機能とは別です。

### 処理中のエージェントへ追加指示を送る

エージェントが動いている間に入力欄からメッセージを送ると、キューに入ります。対応する経路では、同じ文書の条件を共有する通常のメッセージを順番・送信者ラベル付きでまとめ、次のターンで処理します。

コマンドや文脈の異なる指示は分割し、Claude Code CLIを使う経路では1件ずつ処理します。「中断して今すぐ送信」は現在のターンを中断してキューを進める操作で、押した行だけを先頭へ移す意味ではありません。

### Gitパネルでブランチを切り替える

GitパネルのLog上部にある現在のブランチ名を開き、切替先か新規作成を選びます。ローカルだけでなくリモートにあるブランチも対象です。Logの表示を絞るフィルターとは別の操作です。

切替前に変更ファイル・実行中セッションの案内を確認します。未コミット変更を自動で破棄・退避・強制上書きする機能ではなく、Gitが切替を拒否する場合もあります。別worktreeで使われているブランチでは、該当セッションを開く案内になります。

### フォルダー内の変更をコミット提案に含める

AIへ、対象フォルダーの変更をまとめたコミット提案を依頼できます。確認画面でフォルダー内の変更ファイルが一覧になり、フォルダー単位・個別に選択してから承認できます。提案された時点ではコミットしません。

無視対象のフォルダー・変更のないフォルダー・入れ子の別Gitリポジトリを指定した場合や、展開後の対象が2,000ファイルを超える場合は、提案が拒否されます。通常のフォルダー内にある無視対象ファイルは除外されます。ほかのセッションだけが編集したファイルは初期状態で未選択です。対象と差分を確認してから承認してください。

### Markdownの入れ子リストを編集する

番号付き項目の下で箇条書き・番号付きリストを編集し、通常どおり保存します。保存時に親の番号の幅に応じたインデントへ整え、ほかのMarkdownツールでも親子の関係を保てるよう修正しました。親の番号が2桁でも子リスト自身の開始番号を保ちます。たとえば、10番の下を `1.` で書いた子リストは1から始まります。全Markdown方言の互換性保証ではありません。

### 手元のWikiをチームのレビューへ反映する

CLIを準備した環境で、`nim wiki publish --init` からチームの公開先を設定し、その後 `nim wiki publish` を使います。実行前の確認には `nim wiki publish --dry-run` を利用できます。`export: false` のページとその配下は公開対象外です。

手元のファイルが正本で、チーム側への一方向の反映です。チーム側で本文が変わったページは黙って上書きせず報告します。対応サーバー・チームへのログイン・権限が必要です。Windows配布物だけでCLIとサーバーまで準備されるわけではなく、実サーバー接続の成功も検証していません。一般公開Webサイトや、このGitHub Wikiの更新、双方向同期とは別です。
