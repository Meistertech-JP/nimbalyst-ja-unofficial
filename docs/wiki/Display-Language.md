# 表示言語の設定

表示言語は日本語・英語・Systemに対応します。現行v0.82.4-ja.1では、通常Windows製品で日英双方向の切替、明示的な`en`・`ja`の再起動後の保持、System選択のja-JPホストでの日本語解決を確認しました。別のOS言語や全画面の条件を網羅するものではありません。旧版の実機確認範囲は[テストと品質検証](Testing-and-Verification)に版ごとに記載しています。

v0.82.3-ja.1では通常製品で英語の設定・メニュー・Project Manager・Workspace表示と、英語設定後の再起動保持を確認しました。表示言語をSystemにした状態で、日本語Renderer・ネイティブメニューと、Ctrl+Qによる正常終了・再起動後の日本語保持も確認しました。同版での明示的な`ja`設定値の保持は未確認でした。修正後の補助エラー警告は日英DOM試験で確認していますが、通常製品での表示は未確認です。これらと以下のv0.82.1-ja.1の観測は先行版の履歴として区別します。

アプリ設定を開き、「アプリ」内の「詳細設定」で表示言語を選択します。英語表示の場合はApplication Settings → Advancedです。選択肢は日本語、英語、システム設定です。

## システム設定の意味

保存する`uiLanguage`は`system`、`en`、`ja`のいずれかです。`system`ではシステムのロケールが`ja`で始まる場合に日本語、それ以外は英語を使用します。未対応言語すべてを翻訳する設定ではありません。

対応する画面とアプリケーションメニューは変更後に更新されます。v0.82.4-ja.1では設定・メニュー・Tracker参照表示の切替と再起動保持を確認しました。v0.82.3-ja.1とv0.82.1-ja.1の観測は、それぞれの版の履歴として区別します。外部スクリーンリーダーによる読み上げ動作は未検証です。

独立したReactルートにも同じライブi18nインスタンスを渡します。実装については[日本語化アーキテクチャ](Localization-Architecture)を参照してください。

## エージェントの言語とは別

`preferredAgentLanguage`はAIエージェントへの応答言語の指示です。`uiLanguage`はアプリ自身の表示言語です。片方を変えても他方と同じ意味にはなりません。外部サービスが指示どおりの言語で応答する保証でもありません。

表示言語を変えても、次の内容は自動翻訳・書換えしません。

- 自分や共同作業者が書いたファイル・ページ名・文書・過去の会話
- 外部サービスから返された応答やエラー詳細
- ブランド名、モデルID、API識別子、Git参照、プロトコル値
- すでに作成・編集したチュートリアル

新規チュートリアルは作成時の表示言語に従います。既存内容を上書きして言語を揃える仕様ではありません。英語が残る場合は[トラブルシューティング](Troubleshooting)でUIとコンテンツを区別して確認してください。全画面の実行時確認は完了していません。
