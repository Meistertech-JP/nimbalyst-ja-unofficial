# 表示言語を変える

設定 → アプリ → 詳細設定 → 表示言語で選びます。英語表示ではSettings → App → Advanced → Display languageです。

- **日本語**：日本語のアプリ表示を選びます。
- **English**：英語のアプリ表示を選びます。
- **System**：OSの言語が日本語なら日本語、それ以外は英語にします。未対応の言語まで翻訳する設定ではありません。

対応する画面とメニューが切り替わります。本版の通常Windows製品では日本語・英語の切替と再起動後の保持を確認しましたが、全画面・全DPI・読み上げ条件を保証するものではありません。

## 文書やAIの回答は別です

表示言語を変えても、既存の文書・ファイル名・会話、外部サービスの応答やエラー詳細は自動翻訳・書換えしません。ブランド名・モデルID等もそのままです。エージェントへの回答言語の設定は別に扱います。

新しいチュートリアルは作成時の表示言語に従いますが、既に作成・編集したチュートリアルは上書きしません。

## 英語が残る場合

UIの一部や動的な表示には未確認・未翻訳の範囲があり、音声ボタンの一部にも英語ラベルが残ります。自分の文書・AIの回答とUIを分けて、[トラブルシューティング](Troubleshooting)を確認してください。

翻訳資源・静的監査・過去版の確認範囲は[テストと品質検証](Testing-and-Verification)、開発上の仕組みは[日本語化アーキテクチャ](Localization-Architecture)に記録しています。
