# English Documentation

The current unsigned Windows x64 edition is v0.82.8-ja.1, based on upstream v0.82.8 commit [`ab9da8f121e4e6fddebc523ced671863e8892ff6`](https://github.com/nimbalyst/nimbalyst/commit/ab9da8f121e4e6fddebc523ced671863e8892ff6). It provides NSIS, portable ZIP, matching source and checksums. Official updates remain disabled; update manually through this repository's Releases. Translation resources contain 27 namespaces and 15,401 keys per language; matching keys and interpolation do not establish complete UI coverage. SQLite migration is included, but migration of all real-user data is not guaranteed. See the [release](https://github.com/Meistertech-JP/nimbalyst-ja-unofficial/releases/tag/v0.82.8-ja.1), [release notes](https://github.com/Meistertech-JP/nimbalyst-ja-unofficial/blob/v0.82.8-ja.1/RELEASE_NOTES_v0.82.8-ja.1.md), and [Testing and Verification](Testing-and-Verification-English) for verification scope and limits. Earlier releases remain available.
