# English Documentation

This unsigned Windows x64 edition is based on upstream v0.82.3 commit `84dcc00f3cd0abbb36eafc6bfad9389f960076db`. Official updates remain disabled. Resources contain 27 namespaces and 14,795 keys per language. English screens and restart persistence were checked in the ordinary product. Japanese display through the System language setting, including after restart, was also observed; persistence of an explicit `ja` value has not been checked. Authentication and NSIS installation, upgrade and removal were not exercised on this build. Team recovery requires the updated sync server; recovery with a real organization and server end-to-end compatibility remain unverified. See the [release notes](https://github.com/Meistertech-JP/nimbalyst-ja-unofficial/releases/tag/v0.82.3-ja.1) for verification limits.
