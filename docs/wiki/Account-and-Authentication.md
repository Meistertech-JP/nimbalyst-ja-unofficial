# アカウントとログイン

**Nimbalystへのログインと、AIエージェントの認証は別です。** Nimbalystのアカウントは正規のNimbalystサービスを使います。この非公式版が別のアカウントサービスを提供するものではありません。Claude・Codex・Grok等を使うには、それぞれのサービスの設定・認証も必要です。

## メールでNimbalystへログインする

1. 設定 → アカウントからメール認証を開始します。
2. **アプリを起動している同じWindows PCで**メールのリンクを開きます。認証中はアプリを開いたままにします。
3. ブラウザーでの処理後、アプリのアカウント表示が更新されたことを確認します。

使用済み・期限切れのリンクなら、PCのアプリから新しいメールを送ってください。メール内リンク・認証コード・Cookie・トークンを他人へ送らないでください。

## スマートフォンで開くと接続できない理由

認証後に戻る127.0.0.1は、そのブラウザーを実行している端末自身です。スマートフォンでリンクを開くと、PCではなくスマートフォンへ戻ろうとするため、PC上のアプリへ結果を返せません。

URLを書き換えたり、外部向けにポートを開放したり、別アプリの関連付けや保護設定を変えたりする必要はありません。同じPCで新しいリンクを開いてください。

## 保存とサインアウト

Windowsでは認証情報を暗号化して保存します。暗号化保存に失敗した場合、平文へ切り替えずエラーを通知する実装です。設定のアカウント画面で通常のサインアウトを行えます。

サインアウトによるこのアプリのローカル情報の削除と、サービス側のセッション失効・アカウント削除は別です。後者まで確認したものではありません。

## 確認範囲と困ったとき

本版では通常Windows製品の専用環境でメール認証、再起動後の復元、サインアウトを確認しました。すべての配布形態で新規認証を再実施したものではなく、Google認証・特殊復旧・サービス側失効も未確認です。詳しい製品形態・集計・過去版の結果は[テストと品質検証](Testing-and-Verification)、現在の注意は[制限事項](Compatibility-and-Limitations)へ分けています。

公式版とは別の設定・データを使い、`nimbalyst://` の既定ハンドラーを取得しません。ただし公式版との同時利用はサポートしません。診断のためにプロファイル全体や認証リンクを添付しないでください。[トラブルシューティング](Troubleshooting)も参照してください。
