# Security Policy

The contact and response commitments below belong to upstream Nimbalyst. They do not establish a security response service for the unofficial Japanese edition. For a fork-specific issue, use a private reporting channel only if GitHub offers one for [this repository](https://github.com/Meistertech-JP/nimbalyst-ja-unofficial/security). Do not put credentials, private documents or exploit details in a public issue. No response-time commitment is made for this fork.

If you believe you have found a security vulnerability in Nimbalyst, please do
not open a public issue.

Report it privately to:

- `security@nimbalyst.com`

Please include as much detail as possible:

- affected component or package
- steps to reproduce
- impact assessment
- any suggested remediation

Nimbalyst will acknowledge receipt and work to validate and address legitimate
reports as quickly as practical.
