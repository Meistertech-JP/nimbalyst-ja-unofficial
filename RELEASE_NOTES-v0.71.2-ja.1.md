# Nimbalyst 日本語版（非公式） v0.71.2-ja.1

Nimbalyst v0.71.2（`59ab7eaf8c995840a37766c65a09307506b87a2b`）をベースに、デスクトップUIの日本語表示を追加したソースプレビューです。表示言語は日本語と英語から選択できます。

公式NimbalystのGitHub Releasesを使う自動更新とアプリ内更新確認は無効です。

## 制限事項

- 公式版と本版は `nimbalyst://` 認証用URLプロトコルを共有します。公式Nimbalystとの同時利用はサポート対象外です。同じWindows環境に両方をインストールすると、認証リンクが意図しないアプリケーションで開かれる場合があります。
- Windowsバイナリは含まれていません。配布用パッケージでの認証コールバックを検証できていないため、バイナリ公開を保留しています。
- このプレビューはソースコードのみを提供します。独自の自動更新機構はありません。

# Nimbalyst — Unofficial Japanese Edition v0.71.2-ja.1

A source preview based on Nimbalyst v0.71.2 (`59ab7eaf8c995840a37766c65a09307506b87a2b`) with Japanese localization for the desktop UI. The display language can be set to Japanese or English.

Automatic updates and in-app update checks using official Nimbalyst GitHub Releases are disabled.

## Limitations

- This edition and the official Nimbalyst application share the `nimbalyst://` authentication URL protocol. Running both applications on the same Windows system is not supported; authentication links may open in the wrong application.
- No Windows binaries are included. Binary publication is on hold because authentication callbacks have not been verified in a packaged Windows build.
- This preview provides source code only and does not include its own update mechanism.
